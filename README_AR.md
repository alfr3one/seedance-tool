# دليل تشغيل المشروع على جهازك

هذا المشروع (Dola Render Gateway) يشغّل خادماً محلياً على جهازك مع لوحة تحكم في المتصفح، لتوليد فيديوهات Seedance عبر حساباتك في Dola.
بعد التشغيل تفتح لوحة التحكم على العنوان: `http://127.0.0.1:8000/`

## ما الذي تحتاجه

- Python بإصدار 3.12 أو 3.13. لا تحتاج Node.js ولا npm لتشغيل اللوحة.
- اتصال إنترنت في أول تشغيل، لتنزيل المكتبات ومتصفح Chromium خاص بالأداة (حوالي 400 ميجابايت).
- حساب Google أو أكثر تدخل به إلى موقع Dola.

## 1) تثبيت Python

**ويندوز**

1. حمّل Python 3.12 من: https://www.python.org/downloads/windows/
2. في أول شاشة من برنامج التثبيت فعّل الخيار **Add python.exe to PATH**، ثم اضغط **Install Now**.

**ماك**

1. حمّل Python 3.12 من: https://www.python.org/downloads/macos/ وثبّته.
2. افتح Applications ثم مجلد Python 3.12، وانقر مرتين على **Install Certificates.command**. هذه الخطوة ضرورية لنجاح تنزيل الفيديوهات.

## 2) تنزيل المشروع

- من صفحة المستودع على GitHub اضغط **Code** ثم **Download ZIP**.
- **فك الضغط أولاً** (Extract All) قبل تشغيل أي ملف، ولا تشغّل الملفات من داخل ملف ZIP مباشرة.
- يُفضَّل وضع المجلد في مسار قصير بأحرف إنجليزية ومن غير مسافات، مثل `C:\seedance-tool`.

أو باستخدام git:

```
git clone https://github.com/alfr3one/seedance-tool.git
cd seedance-tool
```

## 3) التشغيل

**ويندوز:** انقر مرتين على الملف `start-windows.bat`.

- في المرة الأولى ينشئ بيئة `.venv`، ثم يثبّت المكتبات ومتصفح Chromium. يستغرق ذلك بضع دقائق.
- إن ظهرت رسالة حماية من ويندوز اضغط **More info** ثم **Run anyway**.
- عندما يجهز الخادم يفتح المتصفح تلقائياً على لوحة التحكم.
- **اترك النافذة السوداء مفتوحة** طوال العمل. للإيقاف اضغط `Ctrl+C` أو أغلق النافذة.

**ماك:** افتح Terminal واكتب (مع تعديل المسار حسب مكان المجلد عندك):

```
cd ~/Downloads/seedance-tool
bash start-mac-linux.sh
```

في المرات التالية شغّل نفس الملف، وسيقلع الخادم خلال ثوانٍ.

## 4) الاستخدام

1. **إضافة حساب:** من تبويب **Accounts** اضغط **+ Add Account** واملأ:
   - **Name:** اسم قصير بحروف إنجليزية أو أرقام، مثل `acc1`.
   - **Email** و **Password:** بيانات حساب Google الذي تدخل به إلى Dola.
   - **TOTP Secret (2FA):** اختياري، ويُملأ فقط إن كان التحقق بخطوتين مفعّلاً. المطلوب هو **المفتاح السري** الذي يظهر عند اختيار "Can't scan it?" أثناء إعداد Google Authenticator، وليس الرمز المكوّن من 6 أرقام.
   - ستفتح نافذة Chromium وتسجّل الدخول تلقائياً. إن ظهر اختبار reCAPTCHA فحلّه بيدك داخل النافذة ولا تغلقها.
2. **توليد فيديو:** من تبويب **Generate Video** اكتب البرومبت، واختر الموديل (Seedance 2.0 أو 2.5) والأبعاد والمدة (10s أو 15s أو 30s)، ثم اضغط **Generate Video**. اترك خانة API Key فارغة.
   - مدة 15 ثانية تعمل دائماً عبر Seedance 2.5.
   - قد تفتح نوافذ Chromium أثناء توليد فيديوهات 10 و30 ثانية. هذا طبيعي، فلا تغلقها.
3. **متابعة المهام:** من تبويب **Task Queue**، وفيه أزرار إعادة المحاولة (Retry) والاستئناف (Resume) والإلغاء (Cancel).
4. **عدة فيديوهات معاً:** من تبويب **Batch Gen** تكتب برومبت لكل حساب، فتعمل الحسابات بالتوازي.
5. **الفيديوهات الجاهزة:** تُحفظ في مجلد `downloads` داخل مجلد المشروع. وفي تبويب Accounts زر لتنزيل آخر فيديو مكتمل لكل حساب في ملف ZIP.

لكل حساب حد يومي من الفيديوهات، وتعرض الأداة الرصيد المتبقي في عمود **Remaining**.

## البروكسي / VPN

- عند أول تشغيل يلغي السكربت البروكسي الافتراضي للأداة (`http://127.0.0.1:7890`)، فيستخدم Chromium اتصالك العادي أو الـ VPN المفعّل على الجهاز.
- إن لم يفتح موقع Dola في بلدك فشغّل VPN. وإن كان برنامج الـ VPN يوفّر بروكسي محلياً (مثل `http://127.0.0.1:7890` أو `socks5://127.0.0.1:1080`): ادخل تبويب **Settings**، وفعّل **BẬT PROXY CHO CHROMIUM**، واكتب العنوان، ثم اضغط **Kiểm tra kết nối** لاختبار الاتصال، وبعدها **Lưu proxy** للحفظ.
- البروكسي الذي يحتاج اسم مستخدم وكلمة مرور غير مدعوم.

## معاني الكلمات الفيتنامية في الواجهة

| في الواجهة | المعنى |
|---|---|
| Lưu | حفظ |
| BẬT PROXY CHO CHROMIUM | تفعيل البروكسي لمتصفح Chromium |
| Kiểm tra kết nối | اختبار الاتصال |
| Lưu proxy | حفظ البروكسي |
| Số luồng chạy song song | عدد الفيديوهات التي تُولَّد في الوقت نفسه |
| Tải video hàng loạt (ZIP) | تنزيل الفيديوهات دفعة واحدة (ZIP) |

## حل المشاكل

| المشكلة | الحل |
|---|---|
| `Python 3.10 or newer was not found` | ثبّت Python 3.12 مع تفعيل **Add python.exe to PATH**، ثم شغّل الملف من جديد. |
| `[Errno 10048]` أو `address already in use` | المنفذ 8000 مشغول. شغّل `start-windows.bat 8001` (أو `bash start-mac-linux.sh 8001`) وافتح `http://127.0.0.1:8001/`. |
| فشل تثبيت المكتبات | استخدم Python 3.12، واحذف مجلد `.venv`، ثم شغّل الملف من جديد. |
| فشل تسجيل دخول حساب | راجع الملف `logs/account-login.log` داخل مجلد المشروع. |
| فشل تنزيل الفيديو على الماك (`CERTIFICATE_VERIFY_FAILED`) | شغّل **Install Certificates.command** من مجلد Python 3.12 داخل Applications. |

بعد تحديث المشروع (نسخة جديدة أو `git pull`) شغّل نفس الملف كالعادة، وسيعيد تثبيت المكتبات تلقائياً إن تغيّرت.

## ملاحظات أمان

- لوحة التحكم تعمل على `127.0.0.1` فقط، أي أنها تفتح من جهازك وحده ولا تظهر لبقية الأجهزة على الشبكة.
- لا تشارك مجلد `accounts` ولا الملف `.env.local` ولا ملفات `*.db`، لأنها تحتوي جلسات تسجيل الدخول لحساباتك.
- لا تفتح نفس الحساب من نسختين للأداة في الوقت نفسه.
